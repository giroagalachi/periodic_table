# periodic_table
This repository contains files tha create two periodic tables; one interactive and one graphical. This was my first attempt using pyQT. The code also showcases my used of object-oriented programming.

To use: run __main__.py to create the interactive periodic table. 
The periodic table is created from the csv file containing all the elements. 
After closing the PyQT aplication screen, the plotted periodic table will apear.
